## 🎯 What I Learned

Today, I learned why we move from a normal Node.js HTTP server to the **Express.js framework** and how Express makes backend development simpler, cleaner, and easier to manage.

### 🔹 Key Concepts Covered

- **Node.js HTTP Server → Express.js**  
  Understood how Express simplifies server creation, routing, and request/response handling compared to using the built-in `http` module directly.

- **CRUD Operations**  
  Learned the basic concept of **Create, Read, Update, and Delete**, which is fundamental when working with data in backend applications.

- **HTTP Methods**  
  Explored how different HTTP methods are used:
  - `GET` → Retrieve data
  - `POST` → Create/send data
  - `PUT` → Update data
  - `DELETE` → Remove data

- **Middleware**  
  Learned what middleware is and how Express middleware can process a request before it reaches the route handler. Also learned about `express.json()` for handling JSON data sent in requests.

- **API Routes**  
  Practiced creating routes with Express and understanding how different endpoints respond to different HTTP methods.
