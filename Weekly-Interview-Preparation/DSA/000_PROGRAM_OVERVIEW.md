## ▶️ How to Run the Programs

To run and check what each JavaScript file in the DSA folder does:

### 🌐 Method 1: Run in Chrome

1. Create an `index.html` file.
2. Add your JavaScript file using:

```html
<script src="js-file-name.js"></script>
```

3. Open `index.html` using **Live Server** in VS Code.
4. Open Chrome and press **F12**.
5. Go to the **Console** tab to see the output.

💡 You can install the **Live Server** extension from the VS Code Extensions marketplace.

### 🟢 Method 2: Run with Node.js

You can also run JavaScript files directly using **Node.js**.

For programs that require user input, install `prompt-sync`:

```bash
npm install prompt-sync
```

Then run the file:

```bash
node file-name.js
```

💡 You can search YouTube for a detailed setup and installation process.
