What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

HTML allows us to create headings, paragraphs, images, links, lists and many other elements.

Why Learn HTML?

HTML is one of the fundamental technologies used to build websites.

What are semantic tags?

Semantic tags are HTML elements whose names describe the purpose of their content.

Examples include header, main, section, article, aside and footer.
