CSS UNITS DEMO

Understanding CSS Units

Resize the browser window and inspect the examples below. Each section demonstrates how a different CSS unit behaves.

1. px — Pixels

Definition: A fixed CSS length unit. The declared value does not scale because the parent element changes size.

Use case: Borders, icons, small fixed spacing, and precise UI details.

Width: 200px
Height: 100px

Working: The box stays approximately 200px wide and 100px high even when the parent becomes wider or narrower.

2. % — Percentage

Definition: A relative unit whose result depends on the relevant containing/parent value for the property.

Use case: Fluid widths, columns, progress bars, and layouts.

Width: 60% of parent

Working: If the parent is 800px wide, 60% gives about 480px. If the parent becomes 500px, the box becomes about 300px.

3. vh — Viewport Height

Definition: 1vh equals 1% of the viewport's height.

Use case: Hero sections, full-screen layouts, and vertical spacing.

Height: 25vh

Working: On a 800px-tall viewport, 25vh is 200px. Change the browser height to see the box change.

4. vw — Viewport Width

Definition: 1vw equals 1% of the viewport's width.

Use case: Responsive widths, large headings, and viewport-based spacing.

Width: 50vw

Working: On a 1200px-wide viewport, 50vw is 600px. Resize the browser horizontally to see it change.

5. em — Relative to Font Size

Definition: For most properties, em is based on the element's computed font size. For an element's font-size, em is based on the inherited font size from its parent.

Use case: Components where spacing and sizing should scale with typography.

Parent font-size: 20px

Padding: 2em
Width: 15em

Working: Because the box has a 20px font size, 2em padding is 40px. If the component's font size changes, its em-based dimensions change too.

6. rem — Root em

Definition: rem is relative to the root HTML element's computed font size.

Use case: Consistent typography, spacing systems, and accessible scaling.

Width: 20rem
Padding: 1rem

Working: With the demo's root font size set to 16px, 20rem = 320px and 1rem = 16px.

7. vmin — Smaller Viewport Side

Definition: 1vmin equals 1% of the smaller value between viewport width and viewport height.

Use case: Shapes and elements that should fit within either orientation.

Width: 30vmin
Height: 30vmin

Working: If the viewport is 1200×800, the smaller side is 800px, so 30vmin = 240px.

8. vmax — Bigger Viewport Side

Definition: 1vmax equals 1% of the larger value between viewport width and viewport height.

Use case: Large decorative elements, oversized backgrounds, and responsive art.

Width: 20vmax
Height: 20vmax

Working: If the viewport is 1200×800, the larger side is 1200px, so 20vmax = 240px.

9. dvh — Dynamic Viewport Height

Definition: 1dvh equals 1% of the current dynamic viewport height. It is particularly useful on mobile browsers where browser UI can expand or collapse.

Use case: Mobile full-screen sections, menus, dialogs, and app-like layouts.

Height: 30dvh Resize or use a mobile browser to observe viewport changes.

Working: The element uses the currently available dynamic viewport height rather than a fixed pixel height.
