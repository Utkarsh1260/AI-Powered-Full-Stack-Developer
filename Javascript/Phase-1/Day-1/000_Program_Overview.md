### 📌 Folder Overview

This folder contains **basic JavaScript programs** covering fundamental and commonly used JavaScript concepts. It demonstrates JavaScript execution with Node.js, variables, data types, type conversion, truthy and falsy values, operators, strings, numbers, conditionals, loops, `break` and `continue`, and basic problem-solving through mini projects.
