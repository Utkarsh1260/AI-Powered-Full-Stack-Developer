### 📌 Folder Overview

This folder contains basic JavaScript programs demonstrating arithmetic, increment and decrement, assignment, comparison, equality, logical, short-circuit, and ternary operators. It covers mathematical calculations, variable updates, comparison of values and data types, logical condition evaluation, short-circuit behavior, and conditional expressions. Each program uses practical examples and console.log() to display results and understand how different JavaScript operators work.
---

### 📌 Programs

| S.No. | Program / Project Question | File Name |
| ----: | -------------------------- | --------- |
| 1 | Write a JavaScript program to demonstrate arithmetic operators using two numbers, a = 10 and b = 3. Perform addition (+), subtraction (-), multiplication (*), division (/), modulus (%), and exponentiation (**), and display the results using console.log(). | `arithmetic-operators.js` |
| 2 | Write a JavaScript program to demonstrate increment (`++`) and decrement (`--`) operators. Show how pre-increment (`++x`), post-increment (`x++`), pre-decrement (`--x`), and post-decrement (`x--`) work. Also, demonstrate the difference between pre-increment and post-increment by assigning their results to separate variables and displaying the values using `console.log()`. | `increment-decrement-operators.js` |
| 3 | Write a JavaScript program to demonstrate assignment operators using a variable `x = 10`. Perform addition assignment (`+=`), subtraction assignment (`-=`), multiplication assignment (`*=`), division assignment (`/=`), and modulus assignment (`%=`). Display the value of `x` after each operation using `console.log()`. | `assignment-operators.js` |
| 4   | Write a JavaScript program to demonstrate comparison operators, including loose equality (`==`), strict equality (`===`), loose inequality (`!=`), strict inequality (`!==`), greater than (`>`), less than (`<`), greater than or equal to (`>=`), and less than or equal to (`<=`). Use appropriate values to demonstrate type conversion in loose comparisons and display the results using `console.log()`. | `comparison-operators.js` |
| 5  | Write a JavaScript program to demonstrate the differences between loose equality (`==`, `!=`) and strict equality (`===`, `!==`). Use examples such as `0 == false`, `"" == false`, `null == undefined`, and `0 === false` to illustrate how loose equality performs type coercion while strict equality checks both type and value. Display the results using `console.log()` and demonstrate why `===` and `!==` are recommended in modern JavaScript. | `strict-vs-loose-equality.js` |
| 6   | Write a JavaScript program to demonstrate logical operators using two Boolean variables, `a = true` and `b = false`. Perform logical AND (`&&`), logical OR (`||`), and logical NOT (`!`) operations, and display the results using `console.log()`. | `logical-operators.js` |
| 7   | Write a JavaScript program to demonstrate the short-circuit behavior of logical AND (`&&`) and logical OR (`||`) operators. Show how `&&` returns the first falsy value or the last value if all values are truthy, and how `||` returns the first truthy value or the last value if all values are falsy. Also, demonstrate how the `||` operator can provide a default username when `userInput` is falsy. Display the results using `console.log()`. | `logical-short-circuit.js` |
| 8   | Write a JavaScript program to demonstrate the ternary operator as a shorthand for `if-else`. Use a variable `age = 20` and check whether the person is an adult or a minor using the condition `age >= 18 ? "Adult" : "Minor"`. Store the result in a variable and display it using `console.log()`. | `ternary-operator.js` |
